Demo: messy report to clean data

A lot of my work turns unreliable input, like scanned lab reports, into structured data a program can use. This is a small interactive version of that idea. It's a simplified demo that runs in your browser, not my production OCR system. My real work is described under Experience.

  1. Edit the report on the left, or press Garble it like a bad scan to add the mistakes scanners make.
  2. The parser reads each line, fixes look-alike characters (a Z for a 2, an l for a 1), and checks the values.
  3. The clean data appears on the right, with a note for every fix.
